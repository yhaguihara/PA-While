# 🔁 PA — While

Repositório de exercícios de Programação e Algoritmos para praticar estruturas de repetição com `while`.

## 📖 Sobre o projeto

O **PA — While** reúne atividades em que uma sequência de instruções é repetida enquanto uma condição for verdadeira. Os exercícios estão separados em pastas para facilitar a organização e a prática.

## ✨ Conteúdo

- 🔄 Exercícios com laços de repetição `while`.
- 🧠 Prática de lógica e controle de fluxo.
- 📚 Atividades organizadas em listas e projetos.

## 🛠️ Tecnologias utilizadas

- **Programação:** consulte os arquivos-fonte para identificar a linguagem utilizada.

## 🚀 Como executar os exercícios

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/PA-While.git
   ```
2. Entre na pasta:
   ```bash
   cd PA-While
   ```
3. Abra os arquivos na IDE adequada à linguagem dos exercícios.

## 🎯 Objetivo de aprendizagem

Praticar laços de repetição e desenvolver o raciocínio lógico para resolver problemas com sequências de instruções.
